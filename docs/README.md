## Ключевые вещи в двух словах

**Код отдельно, файлы отдельно.** Пакет `singbox-subscribe/` — только
исполняемый код. Всё, что вы правите или накапливаете, лежит рядом с ним, в
корне репозитория: `config/`, `source/`, `logs/`, `output/`. Пути в
`config.yaml` пишутся относительно корня.

**`.env` — только секреты.** Обычные настройки оттуда не читаются: они в
`config.yaml`. Приоритет слоёв — CLI → системное окружение → `config.yaml` →
умолчания схемы.

**Ничего не обязательно.** Программа работает «из коробки»: деплой выключен,
браузерная проверка выключена, а ключи нужны только тем проверкам, которые вы
сами оставили включёнными.
