# Фильтры при генерации конфига

Кроме старого `filter` (включить/исключить узлы по регулярке к **имени** узла)
в шаблоне можно указать ключ `server_filter` — он отбирает серверы по данным
**базы**: профилю доступности, стране, региону, задержке, stable и протоколу.
Это разные вещи: страна и профиль лежат в колонках `servers`, а в самой строке
подписки их может не быть вовсе, поэтому по имени их не отобрать.

```json
{
  "server_filter": {
    "capabilities": {"any": ["Global"], "none": ["speed-blocked"]},
    "exclude_countries": ["RU"],
    "max_ping_ms": 1500,
    "min_stable": 3
  }
}
```

Такой фильтр — это ровно «все серверы, у которых есть Global, кроме России».

Ключи `server_filter`:

| ключ | смысл |
|---|---|
| `capabilities` | объект `any` / `all` / `none` по тегам профиля |
| `include_countries` / `exclude_countries` | кодом (`RU`), флагом или названием (`Russia`, `Россия`) |
| `country_regions` / `exclude_country_regions` | `EU`, `ASIA`, `AMERICAS`, `AFRICA`, `OCEANIA`, `MIDDLE_EAST` |
| `min_stable` | минимальный счётчик жизней |
| `max_ping_ms` | максимальная задержка; серверы с **неизвестной** задержкой не проходят |
| `protocols` / `exclude_protocols` | `vless`, `trojan`, `vmess` и т.д. |
| `name_regex` / `exclude_name_regex` | регулярка по имени строки |
| `require_country` | `true` — оставить только серверы с известной страной |

Проверка строгая: неизвестный ключ, неизвестный регион, нераспознанная страна и
некомпилируемая регулярка **останавливают сборку** с внятным сообщением. Раньше
такая ошибка либо проходила молча (опечатка в ключе просто ничего не делала),
либо роняла всю сборку с `re.error` без указания, какой фильтр виноват.

Страна хранится в базе как эмодзи-флаг и заполнена у части серверов. У остальных
`country` пуст: `exclude_countries` их не тронет, а `require_country: true` отсеет.

Сборка конфига отказывается выполняться, если `route.final` или любое правило
маршрута указывает на группу **без участников**: sing-box такие группы считает
нормальными и молча не выпускает наружу трафик.
